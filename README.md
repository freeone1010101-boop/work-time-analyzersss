## Deployment
1. Put `app.py` and `requirements.txt` in the GitHub repository.
2. Open https://share.streamlit.io/
3. Sign in with GitHub and authorize access to the private repository.
4. Create app → Yup, I have an app.
5. Repository: your private repository
6. Branch: main
7. Main file: app.py
8. Choose a custom app URL if desired.
9. Deploy.

After deployment, open the `streamlit.app` URL on Android/iPhone.
